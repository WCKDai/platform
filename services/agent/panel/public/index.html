Add a gateway provider
node-side key

              
The gateway owns provider keys. On the node, run the command for the provider you want; it prompts for the key. The model appears here after the gateway restarts.

              
invincible cloud add anthropic --id claude
# or: invincible cloud add openai --id gpt
# or: invincible cloud add openrouter --id openrouter
# or: invincible cloud add custom --id my-provider --base-url https://host/v1 --model my-model

              

                
                A provider key is never sent to this browser again.
              

            


            

              
Run an adapter
in a thread worktree

              
An external CLI uses its own account. It runs in the selected thread's worktree, so review the diff before opening a PR. Invincible does not receipt its model calls.

              

                

                

              

              

              

                
                A run can take minutes; the worktree keeps the changes.
